## 📌 Project Overview

PetCart is a modern web application for pet owners to browse and order certified organic pet food products, book veterinary appointments (telehealth and in-clinic), track orders in real-time, and manage pet profiles — all in one place.

## ✨ Key Features

- 🛒 **Product Catalog** — Browse organic, farm-fresh pet food with detailed product views
- 🛍️ **Shopping Cart** — Add items, manage quantities, and checkout
- 🩺 **Veterinary Care** — Browse veterinarians and book telehealth or in-clinic appointments
- 📹 **Live Consultation Room** — Join real-time veterinary consultations
- 📦 **Order Tracking** — Track your orders in real-time
- 🐶 **Pet Profiles** — Manage profiles for your pets
- 🥗 **Diet Calculator** — Get nutrition recommendations for your pets
- 🌿 **Farm Traceability** — See where your pet's food comes from

## ⚙️ Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm

### Step 1: Clone the repository

```bash
git clone <your-repo-url>
cd petcart
```

### Step 2: Install dependencies

```bash
npm install --legacy-peer-deps
```

### Step 3: Configure environment variables (optional)

If using the Gemini AI features, create a `.env.local` file:

```env
GEMINI_API_KEY=your_gemini_api_key
APP_URL=http://localhost:3000
```

### Step 4: Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.

### Step 5: Build for production

```bash
npm run build
npm run preview
```
